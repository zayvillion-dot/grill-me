# grill-me - design record (2026-11-01)

## Origin

A house skill, in daily use since July 2026, run before any significant build, offer, page, or client task. The packaged version preserves its method, with wording restored after review r1: recon first, rounds of 3-5 questions with defaults, a played-back brief, and a confirmation gate.

## What was genericised

- Removed company, person, product, and internal-tool names; roles are now "the user" and "the project's progress log".
- The pricing-ladder example in Recon became a generic pricing-page example.
- Moved the seed questions into `references/question-bank.md` (grouped by task type, each with a default) and the record block into `references/answers-template.md`.
- Description rewritten to triggers only, with no workflow summary.
- Added a Common mistakes table; Red flags now include "8+ questions in one message" and "questions with no default".
- Body kept under 450 words.
